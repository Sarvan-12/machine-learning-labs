# Deep Learning & Reinforcement Learning

A collection of Jupyter Notebooks covering Deep Learning architectures, Sequence Modeling, and Reinforcement Learning concepts using TensorFlow, Keras, PyTorch, and Gym.

---

## Lab Index

| Lab No. | Notebook | Algorithm / Topic |
| :---: | :--- | :--- |
| 01 | [`01_lab_1.ipynb`](01_lab_1.ipynb) | Word Embeddings — training Word2Vec on a custom corpus using Gensim. |
| 02 | [`02_lab_2.ipynb`](02_lab_2.ipynb) | Multi-Layer Perceptron (MLP) Classifier on the Iris dataset using Keras. |
| 03 | [`03_lab_3.ipynb`](03_lab_3.ipynb) | Convolutional Neural Network (CNN) Classifier on the MNIST handwritten digits dataset using PyTorch. |
| 04 | [`04_lab_4.ipynb`](04_lab_4.ipynb) | Autoencoders — image reconstruction on the MNIST dataset using Keras. |
| 05 | [`05_lab_5.ipynb`](05_lab_5.ipynb) | Sequence Modeling — Sentiment Analysis on IMDB movie reviews using LSTM (Keras). |
| 06 | [`06_lab_6.ipynb`](06_lab_6.ipynb) | Time Series Forecasting — predicting airline passenger volumes using LSTM (Keras). |
| 07 | [`07_lab_7.ipynb`](07_lab_7.ipynb) | Transfer Learning — image classification using pre-trained MobileNetV2 on the CIFAR-10 dataset (Keras). |
| 08 | [`08_lab_8.ipynb`](08_lab_8.ipynb) | Reinforcement Learning — custom GridWorld simulation environment. |

---

## Running on Google Colab

1. Open [Google Colab](https://colab.research.google.com/) and upload the desired notebook.
2. Ensure GPU acceleration is enabled for notebooks training deep networks (e.g., Transfer Learning, CNNs).
3. Run all cells to execute training and visualize training performance.
